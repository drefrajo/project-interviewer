# Let Creator Instructions set discovery depth and handoff detail

Some services need thorough discovery; others need a short factual briefing and
explicit delegation. Interview Policy must respect the depth and document length
requested in Interview Instructions instead of imposing a comprehensive Website
specification on every Creator. Short-service rules and commercial limits belong
in a Private Interview Template. The built-in templates remain unchanged.

Generic policy permits grouped factual inputs, reuse of supplied material,
prefilled confirmation and explicit design delegation. A brief target never
authorizes invented facts, an unusable main action or an unresolved scope
conflict. Optional omissions and later file/access delivery are distinct from
those blockers. Platform capabilities are explicit: no Client file uploads or
URL/file inspection. Galleries retain their intended image collection and
grouping/order or delegation, without a product-imposed image-count limit.

The existing state machine and review safeguards remain: factual alignment and
Project Document/copy review form the briefing, followed by Visual Concept
selection and explicit style confirmation, then the immutable Project Submission.
Instructions do not bypass review, change workflow or add a hidden service mode.
The final handoff combines the document with the confirmed Visual Direction;
the preconcept document must not pretend that a style is already selected.

No schema migration, private-template overwrite or frozen-Interview rewrite is
needed. A regression test checks that changing a private template cannot mutate
an already frozen Interview's stored instructions or configuration. Prompt
version 8 identifies the discovery-depth changes for feedback attribution.
Version 9 also clarifies that confirming a blocked or incompatible project is
not an Alignment Checkpoint and cannot authorize ready/document generation.
Versions 10–11 also respect Creator-defined content-preparation responsibilities:
preserve supplied copy when writing is excluded, retain included research as
truthful owned work, and distinguish missing action destinations from later
file delivery. Automated concepts cannot promise access to unseen Client files.
