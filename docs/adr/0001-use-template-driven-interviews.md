# Use template-driven Interviews

Interview is a small, template-driven website discovery product centered on one Creator-owned Interview, one account-free Client conversation, one replaceable Markdown Project Document, three rough Visual Concepts, and one immutable Project Submission. Three application-owned Convex tables hold Creator profiles, Interview Templates, and Interviews; one Convex Agent thread owns each transcript; bounded operation state lives on the Interview; and Convex storage holds generated concept images.
