# Use kind-driven generalized Interviews

Interview uses product-owned Interview Kinds—Website, Privacy, and Custom—to select the behavior and output of each Interview, with one localized built-in prefill for each kind. Interview Templates remain reusable, editable prefills tied to one Interview Kind; they do not govern workflow, because a template alone cannot express fixed or optional Visual Concepts or document-only flows. Each Interview snapshots its kind and concrete Visual Concepts choice: Website includes concepts, Privacy excludes them, and Custom defaults to excluding them while letting the Creator choose. This preserves the existing account-free Client conversation and immutable Project Submission while allowing generalized Project Documents and privacy data-mapping preparation.
