# Confirm the selected visual style and preferences before submission

A Visual Concept selection alone does not explain which parts the Client likes.
Every new visual Project Submission therefore requires explicit keep/avoid
preferences and a separate review of the selected basis with those preferences.
The Client confirms that displayed style before the immutable submission.

The confirmation is an exact reflection of the concept description or annotated
references and the Client's own words. It does not infer new visual requirements.
The server validates the selection and preferences, reconstructs the summary,
and stores it with a server confirmation time. Clients cannot submit a forged
confirmation or complete the flow through an unconfirmed saved draft. Both
the Creator view and exports retain the confirmed direction.

For unsure Clients, Interview discovery and Project Documents distinguish firm
brand requirements from tentative visual suggestions and delegated choices.
Visual Concepts explore materially different art directions within the same
scope. Another concept batch remains available after a tentative selection.
When none fits, no style is agreed until the Client explicitly confirms an
alternative based on references and stated preferences.

Discovery readiness is distinct from final style confirmation. When visual
concepts are included, content, behavior, scope and actual visual constraints
must be aligned before creating the Project Document; palette, typography and
composition may remain open for the concepts. The application renders concepts
after document review. Waiting for their approval during discovery would block
the very step that creates them. Document-only Interviews retain their own
readiness requirements.

Creator Interview Instructions still define service scope; style confirmation
does not change features, content or commercial terms. Concepts and example
imagery remain illustrative rather than final implementation promises.
Historical submissions remain readable without the new fields. Document-only
Interviews retain their existing flow.
