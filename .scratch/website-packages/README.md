# Private Website templates: Start and Complete

Choose **Website** with Visual Concepts enabled. Create two private templates;
use the appropriate language below. Client Language is a separate setting in the
application and must match the intended client-facing language.

| Package | German instructions | English instructions |
| --- | --- | --- |
| Start (€990 net) | [Start DE](templates/start.de.md) | [Start EN](templates/start.en.md) |
| Complete (€1,500 net) | [Complete DE](templates/complete.de.md) | [Complete EN](templates/complete.en.md) |

Copy the complete chosen file into Interview Instructions, replacing the previous
service instructions. Do not append the old scope: it has different prices,
content responsibilities, correction rounds and blog/care terms.

The Creator selects the package before invitation by choosing the template.
Edit its first line's extras/care selection only when purchased. For example:

> Vom Creator gebucht: Start, 990 € netto. Zusatzleistungen: Blog +300 €. Pflege: 240 € netto/Jahr gebucht.

The catalogue near the bottom explains what those selected extras mean; merely
listing the catalogue does not purchase them. Client messages do not change that
selection. No package selector or drefrajo-specific scope was added to generic
product code, and no existing hosted templates/interviews were modified.

The factual briefing stays short, with standard copy review → generated concepts
→ keep/avoid preferences → explicit image-based confirmation. In Start, missing
finished copy is client preparation, not automatic writing. In Complete, unknown
positioning/imagery becomes Creator work, with truthful status and later content
approval before launch.

See [the handoff format](handoff.md), [test results and real simulated conversations](results.md), and [evaluation scope](spec.md). The scope was
checked against the [live website offer](https://drefrajo.dev/en/website) on
2026-10-16, including the blog's supplied launch article. These are private
instructions, not new built-in product templates.
