# Evaluate and improve implementation-ready Website Interviews

Outcome: completed with local implementation and evaluation artifacts; see results.md.

The Project Submission should let a Creator build the website without another
conversation about content or design. Creator service scope is configurable
Interview Instructions, not product policy. Assets, legal text and secure
deployment prerequisites may be supplied separately if the handoff identifies
exactly what is needed, from whom and for what purpose.

Evaluate four fictional clients through actual prompt builders, provider
requests, initial private planning, transcript messages, output parsing,
alignment gating, document generation, revisions and concept seed generation.
Use the requested GPT-6.1 Sol low model for both prompt baselines to isolate
prompt quality from model migration. Evaluate scope-pushing revisions and
render a real concept batch with the updated image model.

All fixtures, harnesses and results stay outside `src`, `public` and `convex`.
No hosted Interviews, payment consumption, notification email or deployment.
Raw generated output belongs in ignored `.scratch/runtime/interview-evaluation`.
Provide a written report with readiness findings, limits, and verification.
