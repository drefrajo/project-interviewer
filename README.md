# Project Interviewer

File-first discovery for freelancers and clients. The complete MVP runs
credential-free in a browser and has production boundaries for Convex, Better
Auth, OpenRouter, and Cloudflare.

Start locally:

```sh
bun install
bun run dev
```

Then open `http://localhost:5173`. See [docs/setup.md](docs/setup.md) for local
verification and hosted-service configuration.
