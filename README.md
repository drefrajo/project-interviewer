# Project Interviewer

File-first discovery for Freelancers and Clients. Local, development, and
production builds all run the complete Convex-backed application with Better
Auth, durable workflows, file storage, and OpenRouter-backed AI roles.

After configuring a Convex development deployment, start locally:

```sh
bun install
bun run dev
```

Then open `http://localhost:5173`. See [docs/setup.md](docs/setup.md) for local,
development, and production configuration, and
[docs/launch-readiness.md](docs/launch-readiness.md) for the machine, human,
credential, and deployment gates.
